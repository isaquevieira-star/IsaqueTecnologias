Projeto Nova-Web - Diretrizes de UI/UX (Página de Login)

1. Princípios de usabilidade em formulários 

Etiquetas vs. Marcadores de posição

O campo é permanentemente identificado pelo label, ao passo que o placeholder atua apenas como exemplo ou guia. Portanto, o placeholder não deve ser usado como substituto do label, já que pode sumir quando o usuário inicia a digitação.

Hierarquia de Visibilidade

O Primary Button, como "Entrar", deve receber maior ênfase visual, pois representa a ação principal. Ações secundárias, como "Criar Conta" e "Esqueci a Senha", devem receber menos destaque.

2. Situações de Validação dos Campos (Input States)

Padrão: borda neutra e rótulo legível.

Focus (Foco): realce na borda ou contorno quando o campo está selecionado.

Error (Erro): borda vermelha e mensagem explicativa abaixo do campo.

Success (Sucesso): sinal visual indicando que o preenchimento está correto.

Disabled (Desabilitado): visual com contraste diminuído para sinalizar que o campo não está disponível.

3. Normas de Acessibilidade

Empregar um contraste apropriado entre textos e fundos, de acordo com as diretrizes da WCAG.

Assegurar um feedback claro para os leitores de tela.

Habilitar a navegação pelos campos com a tecla Tab.
